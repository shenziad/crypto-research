# Stage 20: entropy failure handling and guarded research profile

The five used static backend roles were rebuilt against an isolated checked RNG/transport source: alias lookup, private row lookup, alias GC, selected private head and the full same-function dense baseline. Nineteen linked `BN_rand_range` sites check success before use. On checked failures the worker stops, emits an opaque error, and the supervisor cancels only its owned peer when needed. Operational ABORT is distinct from the fixed-K sampling FAIL event. Old sources, binaries and negative results remain preserved.

31 native fault cases (early/late BN, random-device and selected OS entropy failures) exercised the rebuilt cryptographic code before the final constructor-only guard upgrade. Seven normal module/recovery checks, two wrapper failures and two diagnostic-redaction checks were also recorded. These 31 cases were **not** all rerun on the final images. All five final native images additionally attested nondumpability and stopped under BN injection; fresh complete candidate and dense regressions passed.

The final normal run transferred 1,539,063,616 bytes for candidate and 3,508,012,338 for the same finite-law dense baseline. Local observed times were 31.87 and 66.07 seconds. This single loopback correctness regression is neither a new benchmark campaign nor a general speedup claim. Fresh setup remains charged. The historical dense run that exceeded its old 180-second native timeout remains a failure; its cause is unestablished. New runs explicitly use a 600-second native timeout, a 720-second public pair deadline and one BLAS/OMP/MKL thread per process.

The intermediate core-size-limit-only claim was too broad for this host's piped core handler. Final Python workers and each native after exec apply `PR_SET_DUMPABLE=0` and zero core limits before private input. A public-data SIGABRT probe produced no kernel core flag; RSS budget monitoring remained readable. This does not protect against a privileged host or arbitrary memory compromise. Linux references: [core(5)](https://man7.org/linux/man-pages/man5/core.5.html), [PR_SET_DUMPABLE](https://man7.org/linux/man-pages/man2/PR_SET_DUMPABLE.2const.html).

An additional single Python-randbits injection produced an opaque error, no final output, and owned-peer cancellation. Its original harness failed an overstrict assertion that neither party could start a native: the healthy server had already started and waited. The behavioral conclusion is from a separately labeled posthoc log audit; no rerun or all-passed harness claim. The initial late-OS injection selector miss is likewise retained and excluded from successful fault counts.

Fail-stop testing is not a security proof. The conditional reduction now explicitly distinguishes prefix-simulatable public fault schedules from secret-dependent aborts. A comparison to a nonfaulting ideal needs a uniform operational failure bound in addition to joint cryptographic and statistical terms; no such failure probability is estimated by forced injections. Full-ciphertext known-key circuit privacy, actual-error seeded RLWE/auxiliary-state assumptions, reactive GC/OT with shared AES primitives and deployment observations remain open. The visible-first-proposal counterexample remains valid for that hypothetical exposed view; current proposals are hidden from generation onward, and no current attack is claimed.

Task value is still unestablished. The current structured task has strong public/template substitutes. Personalized generation is only a conditional lead: server-owned information, reliable independent utility adjudication and public/context/retrieval/support-aware controls are prerequisites. No new dataset, training, prompt sweep or sealed-test access occurred. Claims are narrowed to tested functionality, cost and engineering conditional on a useful legal private head. This is not yet a publication-ready end-to-end result.

MoE and C10 remain paused. Work used two low-priority CPU cores and no GPU, with process-tree resource guards and shared-resource checks; no unrelated job was stopped. Detailed patches, exact local commands, receipts and party records remain local. This directory contains only the authorized aggregate summary, with no detailed source, raw party output, adapter weights or private dataset.
