# 有限 SwiGLU 收缩块：正确性与静态模拟证明草稿

2026-10-29。理想 DCF、可信预处理、一方静态半诚实腐化、一次性材料、固定输入的条件性证明草稿。未声称自适应／恶意安全、具体 AES 假设归约或生产代码审计；不包含完整私有 FFN／LLM。

## 功能必须先固定

令 R=Z/(2^63)。两方输入 A∈R^n、B∈Z/(2^32)^n、W∈R^(m×n) 的加法分享。A 是 signed32 值的 R 嵌入；W 是 signed16 整数矩阵。F 是公开固定系数 F22 分段仿射 SiLU，B 的量化定义为

`Q(B)=clip(floor((signed32(B)+128)/256),−32767,32767)`。

输出 Y 为 R64 中整数向量 `floor(W*(F(A)⊙Q(B))/2^34)` 的随机加法分享。公开类型还必须承诺每一行 `Σ_j |W_ij| * max|F| * 32768 < 2^62`。仅称 W 为 signed16 并不足以排除收缩溢出；实验使用固定模型的逐层 L1 界证书。允许泄露含形状、算子系数、尺度、上述公开范围界，不能同时宣称这些统计信息仍完全隐藏。

该界保证 R 中计算的收缩可唯一解释为 signed63 普通整数，再精确右移。若不满足界，协议仍计算模环功能，但不能声称与无界整数收缩相同。

## 通用 masked-unary 模拟引理

考虑公开一元功能 f:G_in→G_out。dealer 均匀采样 r∈G_in，独立分享 r，并生成若干相关 DCF 密钥及掩码函数常数的独立加法分享。在线开示 h=x+r，输出本地式 `evalₚ(h,keyₚ)+cₚ`；c₀+c₁ 是正确性所需常数或独立零值，且单方 cₚ 在其余单方字段、dealer秘密与DCF密钥条件下均匀，输出中系数为1。所有 DCF 使用独立随机根，单方密钥隐藏允许以其秘密参数为辅助信息做混合。

给定腐化方输入分享及理想输出分享 y，采样均匀 h、独立均匀的其余分享字段，模拟全部 DCF 密钥，最后令 `cₚ=y−evalₚ(h,keyₚ)`。按已知输入／掩码分享和 h 重建对方开示消息。h 对固定输入均匀；各加法分享在秘密值条件下均匀；给定其他字段，真实 y 也因 cₚ 均匀。故条件分布与模拟精确匹配，误差仅为 DCF 密钥混合误差。多个 DCF 按独立密钥逐个替换，不假定秘密阈值互不相关。

这是一元功能的联合静态视图引理。它允许输入／输出群不同，但要求模数、规范嵌入及 f 本身由正确性证明固定。不能仅将32位系数改成64位后引用它。

## 第1模块：完整 signed32 的 half-up 舍入

对 k=32、f=8、r均匀、h=(B+r) mod2^k，有恒等式

```
floor((signed_k(B)+2^(f−1))/2^f)
= floor(h/2^f) − floor(r/2^f)
  + I((r mod2^f)<2^(f−1))
  − I((h mod2^f)<((r+2^(f−1)) mod2^f))
  + 2^(k−f) * (I(h<((r+2^(k−1)) mod2^k))−I(r<2^(k−1))).
```

低位部分来自把 `h_low−r_low+2^(f−1)` 除以2^f，商只能为−1、0、1；高位部分同时修正模环回绕和 signed 解释，不能删掉。源代码 `prepare_round` 正好产生两个 DCF 和 `q_const`，`q_const` 是引理中的独立加法分享。结果在 R32 分享，包含 signed32 正边界附近舍入到2^23的情形；不是随机近似截断。

## 第2模块：signed32 clamp 到 R63

公开有限函数 `clip(signed32(x),−32767,32767)` 由循环差分三段描述。`public_spline_fss` 的输入掩码在R32，DCF输出与聚合在R64，最后投影到R63。FSS正确性由已有区间恒等式给出，输出 `refresh` 是引理中的独立零分享。

由于 clamp 的真实值处于[−32767,32767]，R64→R63投影给出该整数的规范R63嵌入。此处只投影分享，不公开真实量化值；R32本地分享直接做signed扩展则不具有同一语义。

## 第3模块：F(A)Q(B) 的分享

融合方案采用 [一次性门原语模拟](20261029_standalone_gate_simulation.md)，在R63直接返回产品分享。它同时处理同一向量DCF中 `(1,α,−rB,−rBα)` 的相关量与 A、B 掩码开示。

标量幂基／长载荷方案先由 masked-unary 引理返回 F(A) 分享，再用独立 Beaver 乘法产生产品分享。selector方案的活动系数＋Horner子模块则使用同一笔记中的显式模拟，再组合独立乘法；不把 α 的相关重用隐藏在“普通独立 Beaver”措辞中。

## 第4模块：私有 down 矩阵乘法

dealer 独立均匀采样矩阵 M∈R^(m×n)、向量 v∈R^n，独立分享 M、v、Mv。模型初始化开示 D=W+M；产品 z 可用后开示 E=z+v。每方输出

`Tₚ=[Mv]ₚ−D[v]ₚ−[M]ₚE+I(p=0)*DE`。

求和为 `(D−M)(E−v)=Wz`。对固定 W,z，D,E 联合均匀。腐化方的 M、v 分享及 Mv 分享联合均匀，虽重构值相关。给定理想 Tₚ，可模拟均匀 D,E 和前两个分享，然后编程 `[Mv]ₚ=Tₚ+D[v]ₚ+[M]ₚE−I(p=0)*DE`。对方开示消息由腐化方分享与 D,E确定。这证明该模块的联合静态视图，不要求公开 W。

提前开示 D 只移动独立预处理相关的消息，不使用尚未计算的 z。初始化成本69730304B已单独计数，不能因移出在线表就把它从总资源中删除。

## 第5模块：signed63 → signed64 精确右移

令 k=63、f=34、h=(T+r) mod2^k。有

```
floor(signed_k(T)/2^f)
= floor(h/2^f) − floor(r/2^f)
  − I((h mod2^f)<(r mod2^f))
  + 2^(k−f)*(I(h<((r+2^(k−1)) mod2^k))−I(r<2^(k−1))).
```

全部输出在R64。`shift_prepare` 的 low、high DCF 和 constant 分别对应式中三项秘密修正；独立 constant 分享满足 masked-unary 引理。结合全域累加界，输出等于普通整数的 floor 而非只在模环上对某个随机代表元做移位。

## 静态全视图的组合草稿

上述图是有向无环的分享功能：B舍入→clamp；A与clamp输出→门产品；门产品与W→收缩；收缩→最终截断。各模块的 dealer 随机性独立，唯一有意相关的 α／Horner 或 rB／门载荷已经纳入同一个模块证明。模块输出含独立可编程加法分享字段，故可先采样每个内部腐化方分享，再条件化模拟相应模块，最终模块使用理想输出分享。各模块的对方消息均由公开开示值和已采样的腐化方字段唯一确定。

在真实协议的五个交换中，把不同模块已经就绪的开示串联在同一消息，只改变消息打包：例如 A 开示和 B 舍入开示并行；标量F开示或selector斜率开示与B裁剪打包。它不改变依赖图，也不共享新的秘密掩码。按实际依赖顺序合成上述条件分布，就得到全静态视图模拟的草稿。误差由所有 DCF 模拟混合之和上界；一组每元素的 spline1、round2、clamp1、每输出shift2，共4n+2m个独立DCF实例，其余为信息论分享模拟。

这一步尚需形式化检查各模块的共享输出功能定义与静态条件化组合细节，不能据此宣称UC、安全预处理分发或自适应组合定理。特别是论文版应把上面的联合静态模拟和在线可组合模拟明确分开，并说明模拟器获取理想输出的时点。当前可以核对每个局部代数与模拟分布；实现正确性由原生逐方、真实两方和GPU/CPU结果另行提供证据。
