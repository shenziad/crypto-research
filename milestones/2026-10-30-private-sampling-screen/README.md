# Fixed-proposal private sampling: closed numerical filter

This is a negative research milestone, not a new secure protocol. It tests three
fixed proposals on Pythia-14M and rejects their direct implementation. The target
interface keeps the sampled token visible only to the client; public proposals
cannot automatically be considered free public randomness for that interface.

Read [the analysis and decisions](notes/20261030_fixed_proposal_sampling_analysis.md)
and the [preregistration](notes/20261030_fixed_proposal_sampling_preregistration.json).
The main result is [raw per-position JSON](results/fixed_proposal_sampling_screen.json).

* 512 calibration and 1,024 heldout positions, independent Wiki/PTB windows.
* Calibration-minimax envelope fails at 1,006 / 1,024 heldout positions; clipping
  changes the target law, with mean conditional TV about 0.10.
* Covering the observed heldouts with each calibrated proposal requires about
  99–124 million trials at failure budget 2^-40. Deduplicated candidates still
  cover at least 99.94% of vocabulary rows. These are oracle diagnostics, not
  certified all-input bounds or measured cryptographic timings.
* A post-hoc optimal proposal over all observed distributions needs 3,972 trials.
  This optimistic result uses heldout information and leaves an open structural
  question; it does not rescue the calibrated candidates.
* One canonical LayerNorm row-envelope construction needs about 10^40.34 expected
  trials at a feasible normalized input. This rejects that envelope, not every
  possible sampler or envelope.
* Independent rational enumeration checks 98,304 trial combinations.

The report treats TCC 2022 secure corrective sampling and ACL 2026 Hyperion as
prior work. No model recovery or other attack experiments are performed.

## Recheck and reproduce

The model-free check uses Python's standard library and leaves archived files
untouched:

```bash
python3 scripts/recheck_algebra.py
```

Numerical scripts deliberately refuse to overwrite their primary result files.
Create a fresh run directory on NEWSMY, copy `experiments/`, `notes/`, `data/`
and `models/` from this milestone, and create an empty `results/` there. Then:

```bash
python3 /absolute/path/to/this/milestone/scripts/prepare_assets.py --asset-root /absolute/NEWSMY/fresh-run
cd /absolute/NEWSMY/fresh-run
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 TOKENIZERS_PARALLELISM=false PYTHONDONTWRITEBYTECODE=1 /path/to/python experiments/fixed_proposal_sampling_screen.py
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 /path/to/python experiments/layernorm_rejection_envelope.py
```

Use a local environment with PyTorch, Transformers, NumPy, SciPy, safetensors and
tokenizers. [environment.json](environment.json) records the framework used for
the teacher forward; the static envelope used the separate CPU environment
recorded there. This is not a tested fresh-machine installer. All model/data
bytes must match included SHA256 manifests; the downloader stops if upstream
content differs. The three numerical scripts and preregistration are frozen.

Model weights, corpus text, selected token sequences, the derived input NPZ,
third-party PDFs and environments are excluded from this archive. The input NPZ
is regenerated by the teacher script and its original hash is in the raw report;
floating-point outputs can depend on runtime/platform. No timing comparison is
claimed, and no large-model extrapolation is justified.
