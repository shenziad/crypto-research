# 固定提案私有 token 采样：功能与必要代价筛选

研究范围：构造、正确性和代价，不开展攻击实验。此处的标准拒绝采样不是新密码原语。数值筛选预注册见同日期 JSON；结果文件生成后另附结论，不根据测试集调整提案。

## 目标接口

目标为模型权重和上下文私有，最终 token 只交给客户端。接受位、首个成功位置、访问的词表行及随机候选均不能未经证明直接公开。论文中的双方获得样本、公开输出或允许额外泄露的采样功能，不自动满足这里的目标。

尤其需要区分“随机候选的边缘分布不依赖输入”和“候选与最终输出的联合分布可模拟”。两者不等价。考虑理想功能仅向诚实客户端给出均匀词表 token Y，服务器没有输出。若真实协议公开至多 K 个候选组成 R，而且成功时 Y 一定属于 R，服务器视图和诚实输出具有相关性。在只允许输出 token 的理想功能中，服务器模拟器没有 Y，所模拟的 R 与均匀 Y 独立，故 Pr[Y∈R]≤K/V。真实协议该事件概率至少 1−δ，联合分布距离至少 1−δ−K/V。这一简单的功能一致性检查说明：不能以“候选来自公开、与查询无关的 q”为由，免费公开候选。这个论证针对通常要求联合模拟诚实输出与腐化方视图的定义；它不声称排除明确把 R 加入理想功能的其他定义。

因此本次筛选的成本是有利的下界式诊断：假定可以免费取得秘密候选对应的 logits，并免费取得归一化常数。既没有实现这些操作，也没有把公开候选方案宣称为安全方案。若转入协议，仍须实现秘密候选选择且给出双方视图的模拟。

## 标准拒绝采样与截断

给定目标分布 p 与固定、全支撑提案 q，若公开包络 M 满足 p_i≤M q_i，每次秘密提出 I∼q，以概率 p_I/(M q_I) 秘密接受。单次成功率 1/M，接受后条件分布恰为 p。固定执行 K 次并秘密选择首个成功，则无接受概率为 (1−1/M)^K。δ 失败预算所需 K 为 ceil(log δ / log(1−1/M))。失败处置必须写入理想功能或计入统计距离；随机停止会暴露依赖输入的成功率。

如果 M 只在校准集成立，直接把接受率截到 1 后，实际条件分布为

q'_i = min(p_i, M q_i) / A，A = Σ_i min(p_i, M q_i)。

单次成功率为 A/M，而非 1/M。代码直接计算 TV(p,q') 与实际无接受概率 (1−A/M)^K。任意失败回退分布的总 TV 可用 TV(p,q') + Pr[无接受] 上界，但不能把校准包络越界当作仍精确采样。采样统计误差、有限随机比特误差和密码安全参数需分别预算。

## 最有利固定提案的观测集下界

对一组固定目标 p_t，令 a_i=max_t p_t(i)。任何共同包络 M 与提案 q 必须满足 M≥a_i/q_i，故 M≥Σ_i a_i。取 q_i=a_i/Σ_j a_j 达到等号（零质量坐标可按支持集处理）。所以观测集上最优固定提案的包络恰为 Σ_i max_t p_t(i)。

此式允许在完整观察测试分布后，给出该有限集合最有利的诊断。不代表事先知道可部署提案，更不是所有上下文的包络证书。本次同时报告：均匀 q、固定校准均值 q、固定校准点态最大 q，以及使用测试信息的 oracle 最优值，避免只报告弱均匀基线。

## 查重

Choi、Dachman-Soled、Gordon、Liu、Yerukhimovich 的 TCC 2022 论文 *Secure Sampling with Sublinear Communication* 已研究 L1/L2/乘积安全采样与纠正采样。作者论文页第 4 章给出了完整对应构造：L2 纠正采样无需先计算联合范数；乘积采样讨论了额外的内积泄露及其代价关系。该模型是双方分别持有非负向量；并不等于在有限环中分享 LLM logits 后可本地指数化。这些先例阻止将“无需归一化的秘密拒绝/纠正采样”本身宣称为新贡献。

原始来源：[TCC 论文](https://www.iacr.org/archive/tcc2022/137470115/137470115.pdf)、[作者论文页第 4 章](https://linshengliu.com/)、[NSF 存档](https://par.nsf.gov/servlets/purl/10396545)。本次浏览作者正文可读；两个 PDF 链接的浏览下载分别遇到 403/502，不能声称已逐页核验最终 PDF。这里没有使用其下界来证明低维 LLM 输出头不可能优化，也没有用额外泄露方案替代严格接口。

相关已完成本地基线：`20261029_norm_bounded_sampling.md` 中标准 Gumbel + 通用比较路线已因普通 32 位强基线和新颖性不足暂缓。本次不重复其精度搜索，也不以 MoE 或量化原生密码计算作为主线。

## 已完成结果与决定

Pythia-14M，固定官方 revision `cf967c0a9a04383db6f7b1108d86b2962634b4ac`，Transformers FP32 CPU eager 前向、float64 softmax。512 个 Wiki 校准位置，另取 512 Wiki 和 512 PTB 位置；三个提案均在留出实验之前固定。非 NumPy 自写模型前向。全部资产复制并逐文件核对原始 SHA256 后保存在本项目 NEWSMY 目录，其他任务资产只读。

词表 V=50,304，K 对应无接受预算 2^-40。表中 oracle K 已免费使用每个留出分布的真实包络，不能按该数值动态公开调整协议长度。共同包络更昂贵：在这些观测分布上，校准均值/点态最大提案分别至少需要约 9,937 万 / 1.236 亿次尝试才能沿用同一个精确包络。均匀提案约 90% 的位置连上述每位置 oracle K 都超过词表长度。这里是尝试次数，不是不同候选行数；重复候选能复用行投影，但所有秘密接受硬币、首成功选择等仍需计价，不将 K 直接等同于 K 个不同矩阵行。

另外对重复候选去重给出有利计价：E[不同候选数]=Σ_i[1−(1−q_i)^K]。在覆盖上述留出分布的共同包络下，均匀/校准均值/校准最大提案的期望不同候选数分别为 50,304 / 50,284.73 / 50,273.99，仍覆盖至少 99.94% 词表。因此这里的负结论没有忽略简单去重缓存。原始补充计算见 `fixed_proposal_sampling_deduplication.json`。校准提案本身依赖模型；如需公开，其泄露也要作为公开参数说明，不能因校准语料公开就断言提案不泄露私有权重。

另一方面，事后针对校准和测试全部 1,536 个分布重新构造的 oracle 最优固定提案 M=143.7501、K=3,972（V 的 7.90%）。这阻止我们作出“任何固定提案都无潜力”的过强结论，但不能当成校准已解决；该提案读取了测试集，也未认证未见上下文。

无需归一化的一个直接构造也已筛除：令 c 为输出权重行均值，最终 LayerNorm 写作 h=γ⊙u+β，1ᵀu=0、||u||₂≤√d。a_i=P((w_i−c)⊙γ)，b_i=(w_i−c)ᵀβ。取 B_i=√d||a_i||₂+b_i、C=Σ exp B_i，q_i=exp(B_i)/C，可只用候选行的 z'_i 以 exp(z'_i−B_i) 接受，成功率 Z'/C。此包络在实数归一化域内有效，但代价过高：本模型 log C=104.1571；合法 u=0 时 log Z'=11.2801，期望尝试次数约 10^40.34。该数字是 float64 范围诊断，未做区间算术认证，不用于部署安全参数；数量级已足以停止这一具体构造。它不是对所有包络或所有采样协议的复杂度下界。

独立精确枚举检查了 98,304 个三次尝试组合，正确覆盖精确包络、包络不足、不同失败率及截断后条件分布。初版校验使用四个硬币字，无法精确表示 1/8 接受率；断言拒绝该有限硬币模型，改用八个硬币字并显式检查所有阈值可表示后通过。此修正仅在独立校验程序，不改变已冻结模型筛选代码或提案。

**决定：停止这三个校准固定提案及逐行范数拒绝包络的直接协议实现；不投入 MPC 或扩展大模型。** 保留观测集最优包络公式作为以后候选的廉价必要筛选。数值上未形成新安全协议或 CCF C+ 贡献，公开候选还存在上述严格功能不一致问题。

结果：`results/fixed_proposal_sampling_screen.json`、`fixed_proposal_sampling_inputs.npz`、`fixed_proposal_sampling_algebra_check.json`、`layernorm_rejection_envelope.json`。输入 NPZ 含词表提案及所选 token，不公开推送语料 token 序列。

## 后续必须采用的强基线

[Hyperion（ACL 2026）](https://aclanthology.org/2026.acl-long.644/) 已做同态逆 CDF 采样，使用 SIMD 前缀和、并行近似 Sign 和相邻差；它还讨论多密文布局及采样误差。其计时是词表向量上的采样，不是生成数万个自回归 token；论文明确保留端到端误差和全流程代价问题。最终 PDF 已下载、哈希记录，并渲染检查第 4 页算法布局；本次未复现其 HE 实现或对其隐私作额外结论。常规 CDF/SIMD 组合应视为已有基线。

私有推测解码也有直接先例：[An Efficient Private GPT Never Autoregressively Decodes](https://openreview.net/pdf?id=On7Ffq7Qde)（正文访问遇验证页）、[ECLIPSE 作者代码](https://github.com/MarkWang1196/ECLIPSE)（README 声明 FHE 推测验证）。仅确认相关先例存在，未据此断言其安全接口完全满足本任务。不能把通用 speculative decoding 简单移入 HE 作为新路线。
