# Stage23: shared-model audit and two guarded implementation fixes

The concrete GC/OT audit identified a public-seed modeling restriction: GC shared_prg seed is sent to the evaluator, which can recompute its stream. An independent-random-stream replacement would therefore be distinguishable; the actual protocol does not perform that replacement. Input-label equations and an ideal-COT conditional Delta-entropy lemma were written with their premises explicit. Concrete COT/CRH/CCRF and the Boolean/host AES tag relation still require one consistent joint model. No current protocol attack or complete proof is claimed.

Two local source issues were isolated. KKOT sender partial batches fill only valid keys but request a full batch of CCRF evaluations; a first short batch can access uninitialized suffix storage, while a later tail can reuse stale keys. The packing/unpacking mask initializer separately shifts a32-bit int by the legal E31 width33 before overwriting it. Public O0 UBSan probes confirm both packing diagnostics, without demonstrating failure or exploitation of the old optimized binaries.

The candidate limits CCRF to the initialized prefix and constructs masks without signed/full-width shifts. Public extracted-method controls preserve ignored key storage with explicit poison; after both fixes,39 fixed module cases passed UBSan, with5 additional legal-width roundtrips. They do not prove whole-library definedness or full OT security. The initial harness compile typo and original diagnostic logs are retained.

Both FABLE variants and all5 native backends were then rebuilt in isolation. Exactly2 SCI headers changed;128 configured compile units retain the checked random-device path, and19 linked BN return checks remain. All5 guard/error attestations and one complete candidate/dense correctness regression passed. On those fresh executions, traffic was1,539,065,655 and3,508,012,338 bytes and local observed times32.38 and61.57seconds. This is necessary functional regression after code changes, not a new speedup claim. After explicit source/hash/guard review the fixed guarded version became the subsequent research entry; the prior guarded tree, versioned profile, binaries and measurements remain intact. Statistical parameters and all old failures are unchanged.

No task/model/prompt/seed sweep or sealed-test access occurred. Public reproducibility and inference-time private information are distinct; a controlled public benchmark can test a private-parameter contract, but does not by itself establish real proprietary utility. No uniquely useful private bounded adapter is validated. The current defensible scope remains conditional protocol/engineering progress with full same-function baselines, explicit joint-model gaps and independent review still needed. MoE/C10 remain paused. Shared KV resources were checked; this work used two low-priority CPU cores for rebuild/regression and no GPU. Only aggregate summary files are published here.
