# LLM Cryptography Research

Constructive research on cryptographic protocols that exploit LLM mathematical structure, with prior-art checks and reproducible local experiments.

This repository records research milestones, including negative results and explicit limitations. Results do not by themselves establish a new cryptographic primitive, deployment security, or a publication tier.

The first completed finite-operator milestone is being prepared for this repository. Model weights and environment caches are stored locally on NEWSMY and are not included.
